# Tavarish Color Palette
### Inspired by Soviet Propaganda Art

This palette is derived from classic Soviet propaganda posters and forms the official color set for Tavarish avatar customization. Each color is assigned an index value (0-255) for use in the avatar data structure.

## Reserved Ranges

| Range | Purpose |
|-------|---------|
| 0–19 | Official Tavarish core palette |
| 20–49 | Reserved for future official expansion |
| 50–255 | Open for community/modder use |

---

## Notes

- All hex values are approximate extrapolations from print sources and may vary slightly from original poster colors
- The palette intentionally skews warm — heavy reds, oranges, and golds dominate, with blue reserved for space/sky contexts
- Pure white (`#FFFFFF`) is intentionally excluded in favor of the warmer **Pravda White**
- Community colors in the 50–255 range should be documented in the wiki to avoid conflicts
